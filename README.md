# 🔥 GitIgnore Forge

A lightweight Python CLI tool that generates a `.gitignore` file based on the selected project type.

## Features

- Python template
- Node.js template
- Java template
- Web project template
- Automatic `.gitignore` generation
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
🔥 GitIgnore Forge
===================================

Available project types:
- python
- node
- java
- web

Choose project type: python

✅ .gitignore generated for python project!
```
